## 4. 说明与清理

- **图片附件格式**（本轮实测定论）：HTTP `POST /api/agent/[id]` 的 prompt 命令必须携带
  `images:[{ type:"image", data:<base64>, mimeType:"image/png" }]`（`type:"image"` 字段必需，
  否则 `Each attachment must be an image`）；顶层 `dataUrl` 会被接受但**不会**进入 user 消息内容
  （模型收不到图）。与 pi-ai 的 `ImageContent {type:"image", data, mimeType}` 一一对应。
- **敏感清理**：测试结束后 DeepSeek key 已从设备 `pi-agent/auth.json` 清空；`/api/local/tmp` 请求体、
  测试工作区目录与两个测试会话 JSONL 已删除；本机无任何 key/请求体残留。
- HOS / Ark 本轮无真机（本机无鸿蒙设备），仅本机构建 unsigned HAP；Android 真机为唯一全链路验证面。
