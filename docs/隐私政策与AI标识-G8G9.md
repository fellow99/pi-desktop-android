## 1. 一句话说明

Pi Desktop 是一个**本地运行**的 AI 编码助手容器：在你的设备本机启动 Node 运行时与 Web UI，把你选择的文件/图片与你的指令发送到**你自己配置的模型服务商**（API Key 由你填写）。应用本身**不收集账号、不做广告追踪、不内置统计/崩溃上报 SDK、不做服务端中转**。

## 2. 我们收集/产生哪些数据，存在哪、发给谁

| 数据 | 是否收集到“我们”的服务器 | 端上存储位置与保护 | 对外发送 |
|---|---|---|---|
| **模型服务商 API Key** | 否（永不上传开发者服务器） | 应用内部存储 `files/pi-agent/auth.json`，权限 **0600**，仅本应用可读；随卸载删除 | 仅在调用模型时以 HTTPS 发给**你配置的服务商** |
| **会话内容/消息**（你的提问、模型回答、思考流） | 否 | 内部存储 `files/pi-agent/sessions/**.jsonl` | 请求体发给你配置的模型服务商以获取回答 |
| **你选择的工作区文件、@提及文件、上传图片** | 否（不离开设备，除模型请求外） | 工作区默认在应用专属外存 `Android/data/<包>/files/workspace`；文件按你的操作读取 | 当你在对话中明确让模型读取/附图时，相关内容随模型请求发出 |
| **终端/命令输出、工具读写** | 否 | 本地会话记录/日志 | 默认不外发；命令若主动联网由命令自身决定 |
| **日志**（app.log / node_bridge.log / logcat 本地） | 否，不自动上报 | 应用内部/外部专属目录，随卸载或清数据删除 | 仅当你**主动**导出给开发者排障时离开设备 |
| **设备标识 / 广告 ID / 精确定位 / 通讯录** | **不收集** | — | 不发送 |

**关键事实（已在真机核验，详见《安卓环境能力清单》T1-4/T1-8）**：
- 不申请通讯录、短信、位置、日历、麦克风、`READ/WRITE_EXTERNAL_STORAGE`、`MANAGE_EXTERNAL_STORAGE` 等敏感权限。
- 访问其他位置文件走 Android **系统文件选择器（SAF）**，由你逐次授权；不做全盘扫描。
- 网络仅在“调用你配置的模型 / 你在终端里主动联网 / 依赖安装（pnpm）/ git 远端操作”时发生；内置 git/pnpm 为纯 JS 实现。

## 3. 数据如何被发送（第三方接收方）

- 应用内置一个兼容 OpenAI 风格的客户端；**模型请求直接从设备 HTTPS 发送到你配置的服务商域名**（如 `api.deepseek.com`），开发者不做代理、不留存副本。
- 第三方服务商对请求内容的处理以其各自隐私政策/服务条款为准。上架文案应列出当前可配置的服务商并给链接（定稿时补全，例如 DeepSeek 官方隐私政策 URL）。
- pnpm 安装依赖会连接你配置的 npm registry（默认官方，可改镜像）；git 操作连接你指定的远端。二者均为用户显式动作。

## 4. 数据控制与删除

- **删除单条会话**：在应用内删除；对应 JSONL 记录移除。
- **清空全部本地数据**：Android「设置 → 应用 → Pi Desktop → 清除存储/卸载」即删除内部存储中的 Key、会话、日志与专属工作区。
- **删除/轮换 API Key**：在应用「设置 → 模型」移除，或删除 `auth.json`。Key 一旦泄露应立即在服务商侧吊销重发。
- 应用 `allowBackup=false`，不参与系统云备份；无跨设备账号同步。

## 5. 权限用途说明（最小权限面）

| 权限 | 用途 |
|---|---|
| `INTERNET` / `ACCESS_NETWORK_STATE` | 调用模型服务、git/pnpm 联网（用户发起） |
| `POST_NOTIFICATIONS`（运行时申请，可拒绝） | 仅用于前台服务常驻通知（长会话保活）；拒绝不影响对话 |
| `FOREGROUND_SERVICE(_DATA_SYNC)` | 长任务期间维持本地服务 |
| 文件/图片 | 通过系统 SAF 选择器，**无需存储权限** |

明确**不申请**：定位、通讯录、短信、通话记录、日历、摄像头/麦克风、安装未知应用、悬浮窗、开机自启、查询全部应用、所有文件管理。

## 6. 儿童与账号

- 不设账号体系、不做年龄门；企业/个人自带 Key 使用。是否适合未成年人由用户及其所选用模型服务商条款约束（定稿时按渠道要求补充）。

## 7. 安全

- 全程 HTTPS（cleartext 被 `networkSecurityConfig` 禁止，loopback 本地服务除外）；本地服务只监听 127.0.0.1 随机端口，主框架外链交系统浏览器。
- API Key 以 0600 落内部存储；不会出现在 UI 回显、日志或崩溃上报（无自动上报通道）。
- 已知边界：在已 root 设备或能访问 adb run-as 的调试场景，本地数据可被高级权限者读取，这是 Android 平台通用特性。

## 附录 A：AI 生成内容标识（G9 / 国内《生成式人工智能服务管理暂行办法》口径）

- 应用提供的对话文本、代码、图像理解回答由**第三方大模型生成**，可能不准确；UI 已明确展示当前所用模型（如 `DeepSeek V4.1 Flash`）与会话中模型身份，用户可据此识别内容来源。
- 建议在产品界面保留/补充：
  1. **显式来源标识**——回答区持续显示模型名与 provider（现状已具备）；
  2. **AI 生成提示语**——首次使用/空态或设置中注明“内容由 AI 生成，请注意甄别，重要决策与代码请人工复核”；
  3. **导出/复制内容**时不剥离模型来源信息（产品决策待定）；
  4. 不提供以假乱真的人脸/语音合成能力。
- 合规注意：内容安全审核实际由**模型服务商**在服务端承担；本应用作为“服务接入/工具”方，应在隐私政策与渠道表单中说明该关系，并在服务商要求的鉴权/实名环节遵从服务商流程。
- **待法务确认**：是否需在应用内固定“AI 生成”角标/水印、内容投诉与举报入口的具体呈现方式。
